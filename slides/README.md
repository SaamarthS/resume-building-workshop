# Workshop Presentation Slides (`slides/`)

This directory houses the presentation deck structure, outline, and delivery assets for the **Resume Building × Overleaf × Google AI Studio Workshop**.

---

## Slide Deck Architecture (75-Minute Core Mapping)

| Slide # | Time Window | Section Title | Key Visual / Content Focus | Facilitator Script Cue |
| :---: | :---: | :--- | :--- | :--- |
| **01** | Pre-session | Title Slide | Event Title, Presenter Names, QR Code to Overleaf Template & AI Studio | *“Welcome everyone. Connect to Wi-Fi and open the links on the screen.”* |
| **02** | 00–01 min | Today's Mission | One-page technical resume, Overleaf basics, AI as an editor | *“Today we are not starting with LaTeX. We start with what is worth putting on a resume.”* |
| **03** | 01–03 min | Meet John Doe | Full-screen display of `John_Doe_Resume.pdf` (20-second critique challenge) | *“Before I tell you what's wrong, reject John Doe yourselves. You have 20 seconds.”* |
| **04** | 03–05 min | The Diagnostic Reveal | The 6 core flaws: 15 ungrouped skills, generic bullets, no evidence, fluff achievements | *“Clean formatting did not save this resume. Let's fix the substance.”* |
| **05** | 05–08 min | The 1-Page Student Standard | Hierarchy: Contact, Education, Categorized Skills, Projects, (Exp/Ach) | *“A section earns its place by adding evidence of technical ability.”* |
| **06** | 08–12 min | Categorizing Technical Skills | Bad: 1 long comma list vs. Good: Languages, Frameworks, Tools | *“If you can't defend it in an interview, do not put it front and center.”* |
| **07** | 12–17 min | The 3-Question Project Test | Relevance (1–5), Technical Depth (1–5), Evidence (1–5) | *“2 to 3 deep, defensible projects beat 6 shallow to-do apps every single time.”* |
| **08** | 17–25 min | The Bullet Formula | `Action Verb + What Was Built + How/Tech + Result/Technical Outcome` | *“Weak: Made a website. Strong: Developed REST APIs using Express and MongoDB.”* |
| **09** | 25–28 min | Welcome to Overleaf | LaTeX mental model: code that compiles; 3-pane layout overview | *“Now that we know what to say, let's control how it appears.”* |
| **10** | 28–35 min | The Essential 8 Commands | Table of 8 core commands + escaping rules (`&`, `%`, `_`) | *“You do not need all of LaTeX today—just these 8 patterns.”* |
| **11** | 35–43 min | Live Coding & Debugging Demo | Live screen share: editing header, project item, deliberate syntax error | *“When a compiler throws an error, don't panic. Read the line number.”* |
| **12** | 43–48 min | Build Sprint (Timer: 5m) | 5-minute countdown clock: Fill Name, Education, Skills, Raw Projects | *“Quiet 5-minute sprint. Roaming TAs are coming around to help.”* |
| **13** | 48–53 min | Meet Google AI Studio | Tool overview; The golden rule: **Editor, NOT achievement generator** | *“AI will not create achievements for you. It helps you express what you already did.”* |
| **14** | 53–58 min | The Master Prompt | Display the copy-paste prompt; breakdown of anti-fabrication rules | *“Look at rule 7: Do NOT invent metrics, users, or technologies.”* |
| **15** | 58–71 min | Live Bullet Iteration | Demonstration using College Event System notes -> 3 output versions | *“Feed your raw project notes in now. Pick the best bullet and verify every word.”* |
| **16** | 71–73 min | Final Pre-Flight Checklist | 1-page check, unescaped characters check, interview defensibility check | *“If you put Docker on your resume, can you answer what a container is?”* |
| **17** | 73–75 min | Takeaways & PDF Export | Recompile, Download PDF, QR code to repository feedback form | *“Your resume is a living document. Keep updating it as you build.”* |
