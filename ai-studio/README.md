## Pedagogical Foundation
* **Platform:** [Google AI Studio (aistudio.google.com)](https://aistudio.google.com/)
* **Model Recommended:** Gemini 1.5 Flash (fast, free tier, zero setup overhead) or Gemini 1.5 Pro.
* **Core Philosophy:** Students do not use AI to invent projects or invent metrics. AI acts as an experienced technical editor translating rough project notes into concise, high-signal resume bullets using the formula:
  $$\text{Action Verb} + \text{What Was Built} + \text{How / Technology} + \text{Result / Technical Outcome}$$
