# Improved Sample Resume (`resumes/improved/`)

This directory is designated for the model **Improved Sample Resume** deliverable ([`DEL-04`](file:///d:/Resume%20building%20event/ROADMAP.md)).

---

## Deliverable Objective
Provide students and facilitators with an exemplary one-page technical resume compiled from Overleaf, demonstrating how John Doe's profile can be transformed into a high-signal candidate profile without fabricating credentials.

---

## Non-Negotiable Content & Design Constraints

1. **Zero-Fabrication Mandate:**
   * **Do NOT invent metrics:** Do not write *"scaled to 1,000,000 daily active users"* or *"reduced latency by 65%"* unless grounded in real benchmarks.
   * If an application was a class/portfolio project without live users, describe the **concrete technical outcome** (e.g., *"implemented role-based access control with JWT and BCrypt; validated data integrity using Mongoose schemas"*).
2. **Skill Categorization:**
   * Group the 15 technologies into clean, scan-friendly categories:
     * **Languages:** Python, Java, C++, JavaScript
     * **Frameworks & Libraries:** React, Node.js, Express, TensorFlow
     * **Databases & Tools:** SQL, MongoDB, Git, Docker, Linux, AWS
3. **Project Bullet Formula:**
   * Apply: `Action Verb + What Was Built + How / Technologies + Result / Technical Outcome`
   * Select 2–3 defensible projects (e.g. E-Commerce Platform, Disease Prediction ML Model).
4. **Header & Contact Information:**
   * Add professional placeholders: `github.com/johndoe`, `linkedin.com/in/johndoe`, `john.doe@email.com`.
5. **Achievements Section Cleanup:**
   * Remove fluff ("interested in coding", "good problem solver").
   * Replace with concrete participation details (e.g., *"Smart India Hackathon 2025 Participant: Built automated triage prototype"*) or reallocate space to expand project technical bullets.
