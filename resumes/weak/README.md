# Weak Sample Resume Baseline (`resumes/weak/`)

This directory contains the pedagogical baseline resume used in the opening **0–5 minute critique exercise** of the workshop.

---

## Files in This Directory
* `John_Doe_Resume.pdf`: The official weak resume PDF presented to students.
* `expected_flaws.md`: Detailed flaw breakdown and recruiter diagnostic questions for facilitators.
* Original source baseline: [`d:/Resume building event/John_Doe_Resume.pdf`](file:///d:/Resume%20building%20event/John_Doe_Resume.pdf).

---

## Core Instructional Guidelines

1. **Do Not Alter the Weak Content:** The weak sample resume content is locked. It serves as an identical baseline for all cohorts.
2. **Pedagogical Nuance:** The PDF is intentionally clean and formatted. Emphasize to students:
   * *“A clean LaTeX format will not get you an interview if the content is generic, unfocused, and lacking evidence.”*
3. **Flaw Categories:** The key issues are:
   - 15 ungrouped technologies
   - Generic 1-line project descriptions
   - Absence of evidence, metrics, or technical specifics
   - Unsupported filler claims in achievements
